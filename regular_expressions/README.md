# Regular Expressions

## About This Project

This project introduces Regular Expressions (Regex), a powerful technique for searching, matching, and validating text patterns. As a Software Engineering student, I am learning how regex can solve real-world problems by identifying specific patterns within strings and processing text efficiently.

## Learning Objectives

Through this project, I explore regular expression syntax, character classes, ranges, quantifiers, and other regex tokens. I practise building and testing patterns using **Oniguruma**, the regular expression engine used by Ruby by default. I also learn how to apply regex to practical problems, such as identifying digits in IP addresses and matching specific character sequences.

## Implementation

The project involves writing Ruby scripts that use regular expressions to scan input strings and return matching patterns. I will practise constructing patterns, testing different inputs, and refining expressions to achieve the expected results.

## Goal

My goal is to strengthen my problem-solving skills and apply regex knowledge to practical software development tasks, including input validation and text processing.
